📊 Planilha de Declaração de Imposto — Excel

Planilha desenvolvida em Microsoft Excel para organização e controle de informações financeiras relacionadas à declaração de imposto.

O projeto foi desenvolvido com foco em organização de dados, automação de cálculos, validação de informações e usabilidade, utilizando recursos nativos do Excel.

🎯 Objetivo

Criar uma estrutura organizada para centralizar informações do titular, informes financeiros e registros de valores, reduzindo a necessidade de controles manuais e facilitando a conferência dos dados.

🗂️ Estrutura da Planilha

👤 TITULAR

Área destinada ao cadastro das informações do titular, como:

- Nome
- CPF
- Data de nascimento
- E-mail
- LinkedIn
- Outras informações cadastrais

🏦 INFORMES

Área destinada à organização dos informes financeiros e informações relacionadas às instituições bancárias.

Possui estrutura para:

- Instituição financeira
- Valores
- Documentos
- Organização dos informes
- Cálculo automático dos totais

📝 NOTAS

Área destinada ao registro e organização das entradas financeiras.

Permite registrar informações como:

- Data
- Categoria
- Descrição
- Valor
- Forma de recebimento

📋 TABELAS

Aba utilizada como base para listas e validações de dados da planilha.

⚙️ Recursos utilizados

- Microsoft Excel
- Fórmulas e funções
- Validação de dados
- Listas suspensas
- Formatação de células
- Proteção de células
- Cálculos automáticos
- Organização estruturada de dados

📈 Aplicações

O projeto demonstra conhecimentos práticos em:

- Organização de dados
- Excel
- Automação de planilhas
- Tratamento e validação de dados
- Construção de ferramentas administrativas
- Análise e consolidação de informações
